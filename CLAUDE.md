# Fiszki z powtórkami

Cel: aplikacja do nauki z fiszek, która częściej pokazuje pytania z błędną odpowiedzią.
Metryka: odsetek poprawnych odpowiedzi przy drugim podejściu do trudnych pytań.

Stos: Next.js (App Router), TypeScript, Tailwind, Firebase Auth, Firestore, Vercel, Playwright.

Zasady pracy:
- Pracujemy krok po kroku. Przed kodem zawsze przedstaw plan i poczekaj na akceptację.
- Zmieniaj tylko pliki potrzebne w bieżącym kroku.
- Bez `any` w TypeScript. Kod musi przechodzić `npm run build` i `npm run lint`.
- Klucze tylko w `.env.local`, nigdy w kodzie.
- Nie zmieniaj modelu danych ani reguł Firestore bez pytania.
- Po każdym kroku opisz krótko, co zmieniłeś i jak to sprawdzić.
- Odpowiadaj po polsku.
